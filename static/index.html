Welcome to Notorious B.P.M.

This is a local music library manager built to look and feel like real hardware. A quick tour of what's here:

  • Four player skins — pick from the Theme menu up top: Hi-Fi (a real VU meter), Cassette (spinning reels), Vinyl (a tracking tonearm), or a clean Default/Graphite view. Switch anytime.
  • Library tools in the toolbar — Tag checker, Duplicate finder, Organize by Artist, and format Convert. Anything that writes to disk (Organize, Convert, iPod import) is marked with a subtle stripe.
  • iPod Classic import — pull tracks off a connected iPod, review and fix them, then move them into your library.
  • Live Radio — thousands of internet stations, with genre-matching and Shazam-style song ID for ones that don't report what's playing.
  • Deletes go to Trash, not gone for good, and a snapshot of your library is taken automatically before any bulk change.

      Review remaining duplicates

      Same song, multiple copies, but nothing safe to guess about which one to keep — format, album, year, and duration are shown for each so you can tell them apart (a lossless FLAC or ALAC copy is worth keeping over a lossy MP3/AAC one of the same song). Check the ones you don't want (at least one copy per song always stays) and delete them together, or one at a time. Deleting sends a file to Trash, not gone for good.

      Tag checker

      Deep scan

      Reads every file's tags directly to catch a missing artist, title, or cover art — the fast scan above can't see these, since a missing artist or title normally falls back to the folder or file name. Can take several minutes for a large library.

      Release years

      A remastered, deluxe, or "Greatest Hits"-style file is usually tagged with that edition's date, not the song's real release year — and this library has no separate "original date" tag to fall back to. This looks up every matching pressing on Deezer and corrects the year to the earliest one found, since a reissue is always later than the original. Runs across your whole library, which can take a couple of hours — it runs in the background, so the app stays usable while it works.

      One genre per artist

      Genre usually comes from whatever a given album was tagged with, so the same artist can end up with a different genre per album (or even per track). This finds each artist's most common genre and applies it to every one of their tracks, so genre stays consistent regardless of which album a track came from. Only artists with a real disagreement are touched — nothing changes for artists that already agree.

      Artist & track names

      Corrects artist and title spelling/capitalization against Deezer's catalog — the same idea as MusicBrainz Picard matching your files against a reference database, using Deezer instead of MusicBrainz since Deezer has no rate limit and MusicBrainz's would turn a full library into a multi-hour job. Only fixes formatting (casing, stray spaces, a missing "The", ...) — it never reattributes a track to a different artist, always keeps any "(Live)"/"(Remastered)"-style suffix exactly as it was, and skips live/rehearsal/demo recordings entirely, since those are too easy to mismatch against a different performance of the same song. Runs across your whole library in the background, same as release years above.

      Verify tags against audio

      "Fix artist & track names" above only confirms the current tags name a real, existing song — equally true whether or not a given file's actual audio is that song, so a file mislabeled with a different real song's tags passes that check. This instead fingerprints the audio itself (Chromaprint/AcoustID — the same tools and account as Live Radio's song-ID feature, so it needs that same free AcoustID API key and fpcalc installed) and reports anything that doesn't match, for you to review — it never changes a tag on its own. Real per-track work (decode + a lookup each, a little under a second per track), so run it on a selection, or on the whole library and let it work in the background. The whole-library run keeps its place: stop it any time (or quit the app) and the next run listens only to what's left.

        Listening stats

        Help

        Most buttons have a tooltip if you hover over them — this covers the things that aren't obvious from that alone.

        🗂 Organize by Artist

        Physically moves every file on disk into a folder named after its Artist tag — this is a real file move, not just a display change. A backup of your library index is taken automatically first, and ratings/playlists are preserved (they follow the file to its new location), but the file move itself isn't something the app can undo. Files already correctly placed are left alone.

        📡 Live Radio

        Browse and play public internet radio stations (via the free Radio Browser directory). Two extra buttons appear once a station is playing:

        🎯 Match My Library looks at your library's most common genre and finds stations playing similar music — no setup needed.

        🔍 Identify this song is Shazam-style song recognition, for stations that don't report what's currently playing. It needs two things installed/configured once: the free chromaprint tool, and a free AcoustID API key (the button walks you through getting one the first time you use it).

        ⤢ Focus mode / ⧉ Pop-out

        Focus mode shrinks the window down to just the player, hiding the library browser — handy for a small, out-of-the-way now-playing widget. Pop-out does the same thing but as a separate floating window instead of resizing the main one.

        ⇄ Backup / Import

        Exports your ratings and playlists to a file you choose (not your music files themselves — just the data about them, matched back up by file path on import). The app also does this automatically to a rotating backup every time it closes, so switching music folders or a bad rescan is always recoverable.

        🗑 Trash

        Deleting a track sends the file to Trash, not gone for good — it can be restored from the Trash panel.

        🏷 Tag / 📑 Duplicates

        Tag scans your library for missing genre, album, year, artist, or cover art, with a one-click Deezer lookup for missing genres. Duplicates finds Live/Remastered/Mix versions of the same song and helps you clean them up, keeping the original album version.

        Playlists vs. Smart Playlists

        A regular playlist is a fixed list of tracks you added yourself. A Smart Playlist is a saved filter (e.g. "5-star Rock from the 90s") that stays live — it always reflects whatever currently matches, even for tracks added later.

        Change history

        Bulk tag edits and file moves, newest first. Undo puts the files and the library back as they were — a tag you've edited again since is left alone.

        Library health

        Checks the library against the files on disk, the cover-art cache and the Trash.
